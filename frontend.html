Mirrors the original protocol.h / sender.c / receiver.c / attacker.c stop-and-wait logic: 256-byte frames, additive checksum mod 256, one attack (except "Drop ACK" and "No Attack", which apply continuously) is fired only on the first data frame it sees, and a 2.0s sender timeout retransmits on either a timeout or a mismatched ACK — same as the real sockets version, just running as one in-browser simulation instead of three processes on ports 5000/6000.
